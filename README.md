# CapturedPerspectives — Multi-page Website Prototype

A redesigned photography company website prototype created for the ongoing CapturedPerspectives project.

## Pages
- `index.html` — Home
- `weddings.html` — Weddings portfolio
- `events.html` — Events portfolio
- `portraits.html` — Portraits portfolio
- `lifestyle.html` — Lifestyle portfolio
- `services.html` — Services
- `about.html` — About
- `contact.html` — Enquiry / contact

## Structure
- `css/style.css` — shared styling
- `js/script.js` — responsive menu, scroll header, reveal animations and prototype form behaviour
- `images/` — place your own final photography files here

## Important prototype note
The website currently uses remote Unsplash image URLs so that the visual design works immediately. Before final submission, replace these with original or properly licensed CapturedPerspectives photography and store the final assets in the `images/` folder.

The contact form is intentionally front-end only for the prototype. It displays a confirmation message but does not send data to a server.

## Recommended GitHub commits
Commit the redesign in logical stages rather than one large upload:
1. `create multi-page site structure`
2. `add shared navigation and footer`
3. `build photography portfolio pages`
4. `add responsive styling and animations`
5. `add services and enquiry pages`
6. `replace prototype photography assets`
7. `final accessibility and content review`
